# warrant-site

The public page for **Warrant**, a Forge app for Jira: scoped, expiring, revocable
authority for AI agents.

- Landing page: https://xarkgg.github.io/warrant-site/
- Privacy statement: https://xarkgg.github.io/warrant-site/privacy.html

Two hand-written HTML files and one stylesheet. No build, no dependencies, no
JavaScript. GitHub Pages serves the branch root.

This page exists for two reasons: to explain the app, and to give the Atlassian
developer console the support link and privacy-policy link it requires before an
app can be shared by installation link.

The product's source is not in this repository.
